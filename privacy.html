Privacy Policy

1. Introduction

Second Life is an independent, one-person project. This Privacy Policy explains what information may be processed when using the Second Life Discord bot.

2. Information Stored

When a server backup is created, Second Life may store information required to recreate the server structure.

This may include server settings, roles, channels, permissions, emojis, stickers, webhooks, threads, Discord IDs, names, image URLs, and related configuration data.

Second Life does not currently store the contents of messages or complete member profiles as part of its server backups.

3. Local Storage

Backup data is stored locally on the computer on which Second Life is running.

Backups are currently stored as local JSON files. The bot does not use an external cloud storage service for these backups.

4. Purpose of Processing

The stored information is used solely to provide the backup and restore functionality of Second Life.

5. Data Sharing

I do not sell or intentionally share stored backup data with third parties.

Data may nevertheless be processed by Discord or other services involved in the normal operation of Discord and the bot.

6. Data Security

Because backups are stored locally, their security also depends on the security of the computer and storage system on which Second Life is running.

I cannot guarantee that stored data will never be lost, damaged, accessed without authorization, or otherwise compromised.

7. Data Deletion

Backup files can be deleted from the local storage at any time.

Since Second Life is currently operated as a local, one-person project, there is no separate online account or user database managed by the bot.

8. Changes to This Privacy Policy

This Privacy Policy may be updated when the functionality of Second Life changes or when necessary.
